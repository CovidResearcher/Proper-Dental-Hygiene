# The-Multi-Pass-Mouth-Protocol

The multi-pass mouth protocol is a thorough daily oral-hygiene method that strongly reduces bacterial load, plaque, debris, and tongue biofilm. Obelisks are RNA elements that colonize certain oral bacteria (notably Streptococcus sanguinis and likely others in the mouth microbiome), reducing those bacterial hosts and their biofilms is a logical way to limit the niches in which Obelisks can persist.
