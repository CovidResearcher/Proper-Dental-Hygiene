\section*{Overview}
This document describes a multi-pass tooth brushing routine designed for thorough debris removal, antiseptic gum care, tongue hygiene, and final fluoride protection. Total time is typically under 5 minutes.

\section*{Tools}
\begin{itemize}[leftmargin=*]
    \item Regular toothbrush (for teeth)
    \item Separate regular toothbrush (for tongue)
    \item Electric toothbrush (for toothpaste)
    \item Mouthwash
    \item Dental floss
    \item Toothpaste (fluoride)
\end{itemize}

\section*{Procedure}

\begin{enumerate}[leftmargin=*, itemsep=0.6em]
    \item \textbf{Initial mouthwash scrub}
    \begin{itemize}
        \item Rinse with mouthwash.
        \item Scrub teeth using the regular toothbrush while utilizing the mouthwash.
        \item Purpose: Scrape off debris (not merely plaque) and provide antiseptic cleaning of the gums.
    \end{itemize}

    \item \textbf{Gargle + tongue cleaning}
    \begin{itemize}
        \item Gargle for 30+ seconds (multiple gargles).
        \item Brush the tongue thoroughly with the dedicated tongue toothbrush, reaching as far back as possible.
        \item Purpose: The tongue is an exposed organ; thorough cleaning is basic hygiene.
    \end{itemize}

    \item \textbf{Flossing}
    \begin{itemize}
        \item Floss all teeth.
        \item Note: Flossing is performed here (not at the end) to avoid potential gum bleeding during the final fluoride brush.
    \end{itemize}

    \item \textbf{Repeat steps 1 \& 2}
    \begin{itemize}
        \item Perform a second mouthwash scrub of the teeth.
        \item Gargle again for 30+ seconds and re-brush the tongue.
        \item Purpose: Clears any minor bleeding from flossing before the final toothpaste step, preventing blood from mixing with fluoride.
    \end{itemize}

    \item \textbf{Final electric brush with toothpaste}
    \begin{itemize}
        \item Brush teeth thoroughly using the electric toothbrush and fluoride toothpaste.
        \item This is the primary cavity-protection step.
    \end{itemize}
\end{enumerate}

\section*{Design Rationale}
\begin{itemize}[leftmargin=*]
    \item Mouthwash is used as the initial scrubbing liquid specifically to remove debris and provide antiseptic action on the gums.
    \item Flossing occurs mid-routine so that any resulting gum bleeding can be addressed in the repeated mouthwash cycle before fluoride application.
    \item A dedicated tongue brush treats the tongue as an exposed organ requiring deliberate, deep cleaning.
    \item The double cycle (steps 1--2 repeated) keeps the process thorough while remaining under 5 minutes total.
\end{itemize}

\section*{Notes}
\begin{itemize}[leftmargin=*]
    \item Maintain separate toothbrushes for teeth and tongue for hygiene.
    \item The electric toothbrush + fluoride toothpaste step remains the key protective action against cavities.
\end{itemize}
